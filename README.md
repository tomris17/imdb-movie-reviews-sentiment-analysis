This repository contains a Natural Language Processing (NLP) solution for sentiment classification using the **IMDB Dataset of 50K Movie Reviews**. The goal is to accurately classify whether a given movie review expresses a positive or negative sentiment.

---

## 📊 Project Overview
* **Objective:** Build a robust text classification pipeline to determine movie review sentiment.
* **Key Steps:**
  * Text Preprocessing & Cleaning (tokenization, removing stopwords, punctuation cleaning, and lemmatization/stemming).
  * Feature Extraction using **TF-IDF Vectorization** (Term Frequency-Inverse Document Frequency) or Count Vectorizer.
  * Model Training using classification algorithms (Naive Bayes, Logistic Regression, or Support Vector Machines).
  * Model Evaluation via accuracy, precision, recall, and F1-score metrics.
  * Interactive web dashboard deployment via **Streamlit** for real-time review sentiment prediction.
